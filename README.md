🏥 Medical Data History – SQL Data Analysis Project
📌 Project Overview

The Medical Data History project focuses on analyzing patient admissions, doctor details, diagnoses, and provincial information using SQL. The goal is to extract meaningful insights from healthcare data by performing structured queries, joins, aggregations, and subqueries on a relational database.

This project demonstrates practical SQL skills used in real-world healthcare data analysis scenarios.

🎯 Objectives

Analyze patient admission and discharge patterns

Understand doctor specialization distribution

Identify common diagnoses across provinces

Generate actionable insights using SQL queries

🗂 Dataset Description

The project uses a relational database named project_medical_data_history consisting of the following tables:

patients – patient demographics (ID, name, gender, birth date)

doctors – doctor information (ID, name, specialty)

admissions – patient admission records (dates, diagnosis, attending doctor)

province_names – mapping of province IDs to province names

🛠 Tools & Technologies

SQL (MySQL / PostgreSQL compatible queries)

Relational Database Concepts

Joins, Subqueries, CTEs, Aggregations

🔍 Key SQL Concepts Used

INNER JOIN, LEFT JOIN, FULL JOIN

GROUP BY & HAVING clauses

Subqueries & Common Table Expressions (CTEs)

Date-based filtering and analysis

Aggregate functions (COUNT, AVG, MIN, MAX)

📊 Sample Insights Generated

Patients with the highest number of hospital admissions

Doctors handling the maximum patient load

Most frequent diagnoses across provinces

Average length of hospital stay by diagnosis
